# Triple C — бета веб-плеера

Спокойный и ритмичный музыкальный плеер: мантры, барабаны, этно-электроника, лофи.
Статический сайт (HTML/CSS/JS), PWA, без сервера.

- `site/` — код плеера, `tracks.json` (каталог), `credits.json` (авторы и лицензии).
- `assets.tgz.b64.part*` — обложки и иконки (оригинальные иллюстрации Triple C), tar.gz в base64; распаковываются при сборке.
- `audio_sources.json` — источники треков; при сборке аудио скачивается и перекодируется в MP3 128 kbps.
- Сборка и публикация: `.github/workflows/pages.yml` → ветка `gh-pages` → GitHub Pages.

Музыка в каталоге принадлежит её авторам и используется по открытым лицензиям (CC0, CC BY 3.0/4.0),
см. `site/credits.json` и страницу «Авторы и лицензии». В Triple C музыка доступна только для прослушивания.
